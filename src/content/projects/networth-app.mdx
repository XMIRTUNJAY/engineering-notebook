## What

Wealthpath answers one question honestly: *where do I stand, and when can I stop?* Assets, liabilities, goals, and transactions CRUD. A 4-step monthly check-in wizard. Forecasting with optimistic/expected/conservative bands plus seeded Monte Carlo p10/p50/p90. What-if scenarios, a standalone calculator suite, CSV/Excel import, full JSON export, and opt-in Postgres cloud sync. Solo-user, desktop/self-host oriented.

## Why this shape

Four constraints drove every decision: financial data must work with zero cloud dependency; a solo user means sync can be last-write-wins; money math must be unit-tested; deployment must be a SQLite file plus `next start`. The result: three storage backends behind one fetch interposer (`local-bridge.ts`), a framework-free calculation engine (`src/lib/engine/`), and 21 API route files with zod validation. Details live in the tutorial series below.

<Callout type="decision" title="Why three databases">
  A single hosted database would violate the privacy constraint; localStorage-only would cap query power and durability. So: server SQLite with migrations, a browser IndexedDB mirror, and Postgres purely for opt-in sync.
</Callout>
